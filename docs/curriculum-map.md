# Curriculum map

Nature Maths covers all six strands of the New Zealand Curriculum, *Te Mātaiaho: Mathematics and Statistics* (2025), for Years 1 to 4 (ages 5 to 8): Number, Algebra, Measurement, Geometry, Statistics and Probability. Each region is one year level; each trail is a topic with Bronze, Silver and Gold rounds of increasing difficulty; each region ends with a mixed creature-rescue challenge.

This file is generated from the generators in `src/curriculum/regions/` so it always matches what the game asks.
